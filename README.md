# audeo-share

複数システムのソースを束ねて共有するモノレポです。各システムはリポジトリ直下の
サブディレクトリとして独立して配置し、それぞれのディレクトリ内に固有のドキュメント・
ソース・テストを持ちます。

## 収録システム

| ディレクトリ | 概要 |
|---|---|
| [`lineage/`](lineage/) | BigQuery のカラムレベル・リネージ（列単位の依存関係）解析システム。View / Scheduled Query / DAG 生成テーブルの SQL 定義を解析し、物理テーブルのカラムから下流オブジェクトのカラムまでの依存関係を管理する。詳細は [`lineage/README.md`](lineage/README.md)。 |

## 構成方針

- 各システムはリポジトリ直下の**兄弟ディレクトリ**として追加する（例: `audeo-share/<system-name>/`）。
- システム固有の README・設計資料・回帰テストは、そのシステムのディレクトリ内で完結させる。
- 新しいシステムを追加したら、上記「収録システム」の表に一行追加する。

## 新規システムの追加手順

1. リポジトリ直下に `audeo-share/<system-name>/` を作成する。
2. そのディレクトリ配下にソース一式（README・ドキュメント・ソース・テスト）を配置する。
3. 本 README の「収録システム」表に、ディレクトリと一行概要を追記する。
